## 📖 Descripción

Repositorio con los trabajos, prácticas y proyectos de la materia **Programación III**. Aquí se desarrollan aplicaciones web, desde la maquetación y el diseño hasta la lógica del lado del cliente y del servidor.

---

## 📚 Contenido de la materia

### 🌐 HTML
Lenguaje de marcado que define la **estructura** de una página web mediante etiquetas (encabezados, párrafos, formularios, enlaces, imágenes, etc.).

### 🎨 CSS
Lenguaje de estilos que controla la **apariencia** del contenido HTML: colores, tipografías, espaciados y diseños adaptables (responsive) con Flexbox y Grid.

### ⚡ JavaScript
Lenguaje de programación que da **interactividad** a la web: manejo de eventos, manipulación del DOM, funciones, peticiones asíncronas y más.

### 🔷 TypeScript
Superconjunto de JavaScript que añade **tipado estático**. Ayuda a detectar errores antes de ejecutar el código y hace los proyectos más mantenibles.

### 🐈 NestJS
Framework de **Node.js** para construir aplicaciones del lado del servidor (backend) con TypeScript. Usa una arquitectura modular basada en módulos, controladores y servicios, ideal para crear APIs REST.

### ⚛️ ReactJS
Librería de JavaScript para construir **interfaces de usuario** mediante componentes reutilizables y estado, lo que permite crear aplicaciones web dinámicas (frontend).

## 🚀 Cómo usar este repositorio

1. Clonar el repositorio:

   `git clone git@github.com:Mc-Eidan/programacion_iii_Chico_Eidan.git`

2. Entrar a la carpeta del proyecto que quieras revisar.

3. Instalar las dependencias (si el proyecto usa Node.js):

   `npm install`

4. Ejecutar el proyecto según las instrucciones de cada carpeta.
